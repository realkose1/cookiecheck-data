개인정보 처리방침

쿠키이써(CookieCheck) · 최종 수정 2026년 9월 1일

쿠키이써는 계정을 만들지 않고 쓰는 앱입니다. 이름, 이메일, 전화번호, 주소 같은 개인을 식별할 수 있는 정보를 요구하지도, 수집하지도 않습니다.

수집하는 것

이용자가 직접 제보를 보낼 때만 다음이 서버에 저장됩니다.

  • 어느 영화에 대한 제보인지 (작품 식별자)
  • 쿠키 유무와 위치(크레딧 중간 / 크레딧 종료 후)
  • 직접 적은 설명 (선택 입력)
  • 기기에서 무작위로 만든 식별자 — 같은 사람이 같은 작품에 여러 번 투표하는 것을 막기 위한 값입니다. 애플이 제공하는 광고 식별자나 기기 고유 번호가 아니며, 앱을 지우면 사라지고 다른 서비스와 연결되지 않습니다.

제보하지 않으면 아무것도 저장되지 않습니다.

수집하지 않는 것

  • 위치 정보
  • 연락처, 사진, 캘린더 등 기기 안의 자료
  • 이용 행태 분석 도구나 광고 추적기 (앱에 넣지 않았습니다)

쓰이는 곳

제보는 쿠키 정보를 바로잡고 채우는 데만 씁니다. 화면에 공개되는 것은 집계된 숫자(있음 n · 없음 n)뿐이며, 직접 적으신 설명은 운영자만 확인합니다. 제보 내용을 광고에 쓰거나, 판매하거나, 제3자에게 넘기지 않습니다.

보관과 삭제

제보 데이터는 Supabase(미국)에 저장됩니다. 삭제를 원하시면 아래 연락처로 알려주세요. 기기 식별자를 함께 알려주시기 어려우므로, 어떤 작품에 어떤 제보를 하셨는지 적어 주시면 찾아서 지우겠습니다. 앱을 삭제하면 기기에 저장된 식별자와 기록은 함께 사라집니다.

외부 서비스

  • TMDB — 작품 정보와 포스터를 받아옵니다. This product uses the TMDB API but is not endorsed or certified by TMDB.
  • 영화진흥위원회(KOBIS) — 일별 박스오피스 관객수를 받아옵니다.
  • GitHub — 매일 갱신되는 쿠키 정보 파일을 받아옵니다.
  • Supabase — 제보를 저장합니다.

이들 서비스에 개인을 식별할 수 있는 정보를 보내지 않습니다.

어린이

이 앱은 특정 연령을 겨냥하지 않으며, 만 14세 미만 아동의 개인정보를 알면서 수집하지 않습니다.
